# tickerandtape-data

Public build and data repository for [tickerandtape.com](https://tickerandtape.com).

The site's source code is private. This repository only holds the build automation (GitHub Actions) and the public
data the site reads: live prices (`live` branch) and the research reports (`research` branch). The published site is
the compiled, compressed output.
